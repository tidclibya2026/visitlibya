# Provider Evaluation Matrix

This is an editable, evidence-first evaluation template. It does not select or recommend a provider. Blocking criteria must pass before weighted scoring is considered. Scores use 0–5; an unverified claim has no score.

## Blocking criteria

Procurement eligibility; PostgreSQL 16 and PostGIS 3.4 compatibility; private database networking; database TLS; backup and PITR; approved data residency; supported data/image export; acceptable security/privacy/legal review. A failed or unknown blocking criterion prevents selection.

## Evaluation rule

For every score, record the specific authoritative source, evidence date, reference, confidence, and technical validation outcome. Marketing claims or undated secondary summaries are insufficient. Prices, regions, SLAs, and support terms require current procurement-verified evidence.
