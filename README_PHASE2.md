# Visit Libya – Figma Phase 2 Pages

This patch keeps the Figma-style homepage identity and applies it to:

- Destinations: white header, large hero, clean cards, simple filters.
- Experiences: Sahara Adventure, Roman Heritage, Coastal Escape, Cultural Immersion, and more.
- Discover: Culture, Food, Folklore, Crafts, World Heritage as a dropdown and a visual hub.
- Plan Your Trip: practical premium planning page.
- Interactive Map: clean map interface with tourism layer chips and accurate-map-only placeholder.

Copy all files to the project root while keeping the existing `imges` folder.
