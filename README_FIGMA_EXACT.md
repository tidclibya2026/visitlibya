# Visit Libya – Figma Make Exact Patch

This patch rebuilds the website to match the Figma Make screenshot style:
- White top navigation like the Figma preview.
- English tourism-first menu.
- Full-screen desert hero.
- Center headline: “Discover the Timeless Beauty of Libya”.
- Red Explore Libya button and white outline Plan Your Trip button.
- Ministry and TIDC names only in the footer.
- Uses local image folder `imges`.

Copy these files into your project root and keep your existing `imges/` folder.
