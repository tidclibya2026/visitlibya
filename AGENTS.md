# Visit Libya Implementation Rules

- Figma Make design is the visual reference.
- Header is tourism-only.
- Ministry and Tourism Information & Documentation Center names appear only in the footer.
- Use local real Libyan images only from the existing `imges` folder and `panel` folder.
- Do not use external placeholder images.
- Use accurate Libya map assets only; do not draw Libya boundaries manually.
- Keep the project compatible with GitHub Pages.
- Preserve visual-first design: full-screen photography, white space, large cinematic typography, destination cards, culture galleries, and map/atlas section.
